ML211 backup

A private backup tool. It stores encrypted backups of the owner's own computer in the owner's own Google Drive, using Google's Drive API with the narrow drive.file permission: it can only see the files it created itself, not anything else in the Drive.

It has one user, the owner. It is not offered to the public and has no sign-up.
