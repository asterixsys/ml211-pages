Privacy policy

Applies to: ML211 backup, a private tool used only by the owner of asterixsys.com. Effective 1 November 2026.

What it accesses

With the owner's permission, the tool uses the Google Drive API with the drive.file scope. That lets it create, read, update and delete only the files and folders it created itself in the owner's Google Drive. It cannot see any other file in the Drive.

What it does with that access

It writes and reads encrypted backup files belonging to the owner. The backups are encrypted on the owner's computer before upload; Google stores only encrypted data.

Sharing

No data is sold, shared, or sent to anyone other than Google (as the storage provider). The tool has no other users, collects no analytics, and uses no advertising.

Google user data

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be withdrawn at any time from the Google account's security settings (third-party access, "ML211 backup").
